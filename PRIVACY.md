# Privacy policy — Viewer Sort for Twitch

Viewer Sort for Twitch does not collect, store, sell, or transmit personal
data. It has no analytics, telemetry, advertising, or external service calls.

The extension reads the current Twitch URL and checks for a sorting control
in the page. When needed, it navigates to the same Twitch page with
`sort=VIEWER_COUNT`. That navigation is an ordinary request to Twitch and
remains subject to Twitch's own privacy policy.

The extension does not read cookies, account credentials, chat messages, or
browsing history. It does not use local or remote persistent storage.

Its access is limited to `https://www.twitch.tv/*` and `https://twitch.tv/*`.
